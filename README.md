# REPROCARE 2.0

Dark, interactive adolescent health education prototype built with React, TypeScript and Vite.

## Learning chapters
1. Reproductive Health and Personal Hygiene
2. Self-Harm
3. Social Communication Problems

The chapter outlines are based on the supplied educational module. Confirm all detailed lesson copy, clinical content, references, and assessment items against the original guide before student use.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Vite writes the production site to `dist/`.

## Cloudflare Pages
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main` (or the branch you choose to publish)

## Important research note
The short knowledge check in this prototype only checks navigation and chapter recognition. It is **not** a validated research pre-test/post-test instrument and does not store or transmit participant data. Use the instrument, consent process, participant safeguards, and data handling approved by the research guide / institution.

## Accessibility and safety
The interface respects `prefers-reduced-motion`. The self-harm chapter is presented as sensitive education; add guide-approved, locally appropriate support resources before publishing it for students. This educational website is not a substitute for professional medical or mental-health care.
